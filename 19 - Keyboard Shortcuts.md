# Editor Shortcuts

## UI Shortcuts

- **`Ctrl + Shift + P`** Command Palette
- **`Ctrl + Shift + E`** Show Explorer
- **`Ctrl +   ̀ `** or **`Ctrl + J`** Toggle panel/terminal
- **`Ctrl + B`** Toggle sidebar
- **`Ctrl + F`** Search in files
- **`Ctrl + Shift + F`** Search in all files
- **`Ctrl + Tab`** Switch between open files
- **`Ctrl + Shift + Tab`** Switch to the previous open file

## General Shortcuts

- **`Ctrl + S`** Save
- **`Ctrl + Z`** Undo
- **`Ctrl + Y`** Redo
- **`Ctrl + C`** Copy
- **`Ctrl + X`** Cut
- **`Ctrl + V`** Paste
- **`Ctrl + F`** Find
- **`Ctrl + H`** Replace
- **`Ctrl + A`** Select All
- **`Ctrl + Shift + Z`** Redo
- **`Ctrl + W`** Close File/Tab
- **`Ctrl + Shift + T`** Reopen Closed Tab
- **`Ctrl + Shift + N`** New Window

## Productivity Shortcuts

- **`Alt+ Arrow Up/Down`** Move a line up or down
- **`Ctrl + Arrow left & right`** Move between word horizontaly
- **`Ctrl + Shift + Arrow`** Select text
- **`Home`** Move to the Beginnig of the line
- **`End`** Move to the end of the line
- **`Shift + Alt + Arrow`** Copy a line up or down
- **`Ctrl + /`** Comment out a line
- **`Ctrl + L`** Select one line or many line when using **L** again
- **`F2`** Rename opening of closing tag at once
- **`Ctrl + D`** Select the next occurrence of the selected text
- **`Ctrl + I`** Sub select similar word whichever are upper or lower case
- **`Ctrl + Shift + L`** Select all occurrences of the selected text
- **`Ctrl + Enter`** Insert a new line below the current line
- **`Ctrl + Shift + Enter`** Insert a new line above the current line
- **`Ctrl + K + Space`** Format one attribute per line of the selected tag only
- **`Ctrl + Shift + A`** Select All within the tag then expand progressively outward
  > **`Ctrl + Shift + A`** Is not build in on VS code to add it in you jason keyword check the following code.

**_Json Shortcut:_**

```json
[
  // Select All within the tag then expand progressively outward
  {
    "key": "ctrl+shift+a", // chose whichever key you want
    "command": "editor.emmet.action.balanceOut"
  }
]
```
