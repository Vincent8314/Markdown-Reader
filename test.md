# Frontend

## Technologies

> **HTML**
> **CSS**
> **JavaScript**

## Responsibilities

The browser handles:

* displaying documents,
* converting Markdown output into HTML,
* applying themes,
* modifying the interface dynamically,
* handling user interactions.

## Markdown Rendering System

A unified system to turn raw, plain text streams into high-fidelity visual cards with custom typography and clean separation rules instantly.
